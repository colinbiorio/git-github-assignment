Git is a version control system that tracks changes to files on your own computer,
allowing you to use commits as save points to return to in case something goes wrong.
GitHub is a website that hosts Git repositories online so that you can back up your 
code, share it with others, and easily collaborate on a project with others.

Branching in Git:
Each branch is a separate line of work. You can make changes on a branch without
touching main, and once everything works you merge it back in, so that the main
branch always stays working while you test out new code.

Pull Requests in GitHub:
A Pull Request is a feature that lets you propose changes you've made on a separate branch to be merged into the main branch. It allows team members to review code, leave comments, and discuss/approve changes to the main branch.
