# git-github-assignment 
This assignment serves as an introduction to using Git, and this repository is proof 
of understanding its purpose, basic syntax, and workflow. 

Through this assignment, I familiarized myself with the manual workflow of Git, as I have worked with Git quite extensively, however this was primarily done by automation. Relearning the commands is helpful in the case that I need to work with Git without the help of AI. I didn't face any significant challenges, although I did notice that I wasn't able to clone the Github using the repo name –– I had to use the url instead. This is likely a small syntactical issue that I overlooked, but it's helpful to know that using the url is a verified, viable method of referring to a repo.
